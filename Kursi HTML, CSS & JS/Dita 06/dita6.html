MESIMI CSS FLEXBOX dhe Media Queries

1. Cfare eshte Flexbox?

Flexbox eshte nje sistem layout-i ne CSS qe na ndihmon te rreshtojme elementet horizontalisht ose vertikalisht ne menyre te thjeshte. Per ta aktivizuar perdorim: 

            display: flex;

2. Boshti Kryesor (Main Axis)

By default, elementet rreshtohen horizontalisht (row).
