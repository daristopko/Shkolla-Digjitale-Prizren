# 01 - Intro AI Agents

## Cka eshte nje AI Agent?

Nje AI Agent eshte nje program qe:

- pranon nje kerkese nga perdoruesi
- e analizon qellimin
- vendos cfare veprimi duhet me bo
- perdor nje ose me shume tools nese duhet
- kthen nje pergjigje finale

## Chatbot vs Agent

Chatbot:
- zakonisht vetem kthen tekst

Agent:
- mund te mendoje ne hapa
- mund te perdor tools
- mund te lexoje file
- mund te ruaje gjendje
- mund te kryeje detyra

## Formula baze

`User Input -> Analyze -> Decide -> Use Tool -> Return Result`

## Shembull i thjeshte

Nese user thote:
`Me llogarit 25 * 16`

Agenti mund te:

1. kuptoje qe kjo eshte detyre matematike
2. vendose me perdor nje calculator tool
3. marre rezultatin
4. ktheje pergjigjen

## Cfare nuk duhet me bo tani

Mos u fokuso menjehere te:

- multi-agent systems
- automation te komplikuara
- framework-e te renda

Fokusi yt i pare duhet te jete:

- logjika e agentit
- tools
- structured output
- workflow i thjeshte
