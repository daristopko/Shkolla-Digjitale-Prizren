# 02 - Konceptet Kryesore

## 1. Input

Cfare dergon perdoruesi.

Shembull:
`Ma lexo kete file`

## 2. Intent

Cfare kerkon ne te vertete useri.

Ne kete rast:
`lexim i file-it`

## 3. Decision

Agenti vendos nese duhet:

- me u pergjigj direkt
- me perdor nje tool
- me kerku te dhena shtese

## 4. Tool

Nje funksion ose mekanizem qe agenti e perdor per veprim.

Shembuj:

- calculator
- file reader
- web search
- database query

## 5. Memory

Mbajtja mend e bisedes ose e rezultateve paraprake.

## 6. Structured Output

Kur agenti kthen rezultat ne forme te rregullt.

Shembull:

```json
{
  "intent": "math",
  "tool": "calculator",
  "answer": 400
}
```

## Rregulli me i rendesishem

Nese e kupton logjiken pa framework, framework-et behen shume me te lehta me u mesu.
